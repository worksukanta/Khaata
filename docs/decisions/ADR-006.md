# ADR-006: Combined monthly dashboard with book-type breakdown

- Status: Accepted
- Date: 2026-10-27

## Context
Khaata is a small mobile-first personal finance app built on an approved SRS v1.0. Agentic coding tools need stable technical decisions.

## Decision
Filter all owned active transactions by date across monthly, event and general books; group expenses by book type.

## Consequences and guardrails
Event expenses count once in month total and can independently count in event budget.

## Change control
Do not silently reverse this decision. Propose a new superseding ADR with tradeoffs and obtain approval before implementation.
