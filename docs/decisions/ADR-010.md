# ADR-010: Shared expenses postponed to V2

- Status: Accepted
- Date: 2026-10-27

## Context
Khaata is a small mobile-first personal finance app built on an approved SRS v1.0. Agentic coding tools need stable technical decisions.

## Decision
Do not introduce sharing tables/roles into V1.

## Consequences and guardrails
V2 will require explicit reporting and debt semantics.

## Change control
Do not silently reverse this decision. Propose a new superseding ADR with tradeoffs and obtain approval before implementation.
