# ADR-008: Session-cookie authentication

- Status: Accepted with deployment verification
- Date: 2026-10-27

## Context
Khaata is a small mobile-first personal finance app built on an approved SRS v1.0. Agentic coding tools need stable technical decisions.

## Decision
Django sessions, CSRF, Secure/HttpOnly cookies; prefer same-site frontend/API.

## Consequences and guardrails
Unrelated host domains may block cookies; verify deployment topology before coding auth integration.

## Change control
Do not silently reverse this decision. Propose a new superseding ADR with tradeoffs and obtain approval before implementation.
