# Step 4 Review Checklist

- [ ] API contract reviewed against approved SRS/business rules.
- [ ] OpenAPI file validated with a 3.1-compatible validator.
- [ ] Auth/CSRF behavior tested in the intended deployment origin setup.
- [ ] Report totals and book-type breakdown use the same transaction population.
- [ ] Money fields are decimal strings.
- [ ] Monthly ensure endpoint is idempotent and DB uniqueness is enforced.
- [ ] Cross-user access tests exist for all resource families.
- [ ] CSV formula injection handling is implemented and tested.
- [ ] UI/UX documents remain aligned with endpoint shapes.
- [ ] Backlog and checkpoint updated after every implementation task.

This is a review checklist, not evidence that the checks have already passed.
